# How to Use Z+ Secure

## Quick Start

1. **Double-click** `Launch Password Generator.bat` to start the application
2. The password generator window will open
3. Choose your password length (minimum 42 characters recommended)
4. Select generation speed (Fast is recommended for most users)
5. Click **"Generate Secure Password"**
6. Click **"Copy to Clipboard"** to copy your password
7. Paste it where you need it!

## Features Explained

### Password Length
- **Minimum**: 42 characters (recommended for maximum security)
- **Maximum**: 128 characters
- Longer passwords are more secure but harder to remember
- For most users, 42-64 characters is a good balance

### Generation Speed
- **Fast (Recommended)**: Best for everyday use. Generates passwords quickly while maintaining maximum security.
- **Standard**: Good balance between speed and security. Use if you prefer a more traditional approach.
- **Maximum Security**: Uses the most secure algorithm. Slightly slower but provides the highest level of protection.

### What Makes These Passwords Secure?

✓ **Military-grade encryption**: Your passwords are created using the same technology used by banks and government agencies

✓ **Completely random**: Each password is unique and cannot be predicted or guessed

✓ **Strong character mix**: Every password includes:
  - Uppercase letters (A-Z)
  - Lowercase letters (a-z)
  - Numbers (0-9)
  - Special characters (!@#$%^&* etc.)

✓ **No patterns**: Unlike human-created passwords, these have no predictable patterns

## Tips for Using Your Passwords

1. **Store securely**: Use a password manager to store your generated passwords
2. **Don't share**: Never share your passwords with anyone
3. **Use unique passwords**: Generate a different password for each account
4. **Change regularly**: Update important passwords every few months
5. **Copy carefully**: Make sure you copy the entire password when using it

## Troubleshooting

**The application won't start:**
- Make sure Java 11 or higher is installed
- Download Java from: https://adoptium.net/

**Password generation is slow:**
- Try selecting "Fast (Recommended)" in the speed dropdown
- Close other applications to free up system resources

**Can't copy password:**
- Make sure a password has been generated first
- Try clicking "Generate Secure Password" again

## Need Help?

If you encounter any issues:
1. Make sure Java is properly installed
2. Check that all files are in the same folder
3. Try running `run.bat` instead
